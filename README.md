# DEM-Rock-Calibration
Code for calibration of rocks shown in the paper "On deep learning calibration for DEM simulation of sedimentary and igneous rocks" that works using the RockFit-DEM code

To cite: "Kholodniak, M., Panchenko, A., Berinskii, I., 2026. On deep learning calibration for DEM simulation of sedimentary and igneous rocks. Powder Technology 470, 121929. doi.org/10.1016/j.powtec.2025.121929"

The calibration script is in the file 'NN_MP.py'. To calibrate your own material, you will have to edit it to provide UCT and BT experimental data.

Results are stored in a separate folder 'result' in a file ResultMusenMaterial.txt
